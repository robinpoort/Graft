# Barlow Semi Condensed

Bundled here as woff2 (bold, latin + latin-ext subsets) so the panel renders
offline and without a request to a third party.

- Typeface: Barlow Semi Condensed, by Jeremy Tribby
- Source: https://github.com/jpt/barlow
- Subsets taken from Google Fonts (`fonts.gstatic.com`): Barlow Semi Condensed v16
- Licence: SIL Open Font License 1.1, https://openfontlicense.org

The OFL allows bundling and redistribution with the software, as done here.

Only the Semi Condensed cut is bundled: it carries the small uppercase labels
and nothing else. Everything the reader actually reads stays on the system font,
so the panel still looks like part of Chrome.
